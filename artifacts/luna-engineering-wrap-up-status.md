## Cross-cutting findings

- **RepresentationPolicy (`lunaRepresentationPolicy.ts`) has not been modified in any phase since Phase 8.** Every new system has been built to conform to its existing contract, never to change it. This is the single most load-bearing piece of evidence that Facility/Consumer privacy boundaries are trustworthy across the whole engineering layer.
- **Every "V1" system follows the identical shape**: one honest, real reference chain + a resolver that derives state fresh every call + a deterministic reference scenario + a `SystemControlBoard` consumer + Oyi vocabulary/intent coverage + explicit DD-numbered disclosure for what's unresolved. This consistency is itself the strongest asset for Architectural Reality V2 — it means "map a real building system to this shape" is a well-defined, repeatable target, not 12 different ad hoc patterns.
- **No system has ever fabricated a capability, a relationship, or a final engineering value.** Every DD (design-decision-required) gap found during 13+ phases of audit remains open and disclosed in its own phase's spec, never silently resolved.
- **The Master Equipment Schedule (`docs/LUNA_MASTER_EQUIPMENT_SCHEDULE.md`) predates Access V1/CCTV V1/Network V1/Drainage V1** and should be regenerated (or explicitly superseded) before Architectural Reality V2 begins, so the ingestion pipeline's own gap analysis starts from a current baseline, not a September snapshot.

## What remains before "the building is done" (it is not)

- DD08–DD17 (see `docs/LUNA_CANONICAL_BUILDING_SPEC.md` and `docs/LUNA_MEP_COORDINATION_SPEC.md`) are all still open — electrical topology/ratings, water demand/storage, drainage discharge/treatment, fire distribution design, HVAC whole-building strategy, security/access coverage design, network topology/resilience, unit-by-unit MEP for 42 of 43 units, structural engineering (loads/reinforcement/member sizing), and site/civil coordination.
- Only Apartment 6A has any registered MEP/device detail; every other unit is architecture-only.
- No system beyond the registered reference chain has been engineered, procured, or approved — every phase's own spec says so explicitly.

This is the correct, honest state to hand off into Architectural Reality V2 / Building Ingestion V1: a proven, consistent, non-fabricating reference architecture with clearly enumerated gaps, not a "finished" building.
