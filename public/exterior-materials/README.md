# Exterior material sources

CC0 texture assets from Poly Haven, downloaded once for this local material study. No runtime API dependency.

License: https://polyhaven.com/license

Powered by Poly Haven. Exact source pages, download URLs, resolutions (1k), hashes and sizes are recorded in sources.json. These are appearance references, not evidence of installed construction materials. Original maps are unmodified.

The `concrete_floor_02` diffuse map is retained for provenance/review but intentionally NOT bound at runtime: its weathering is unsuitable for the clean paving finish. Only its normal and roughness maps are used. Stone is a cast-concrete appearance reference (the historical factory name `limestone` is not a claim about the scan).

## Optional reflection lighting

`venice_sunset_1k.hdr` by Greg Zaal / Poly Haven, CC0-1.0. Packaged locally from the Three.js example distribution; exact download URL/hash in sources.json. Used for reflection/lighting only, never as the background or a claim about Lagos geography. Failure retains the existing procedural environment. This does not add geographic meshes or operational state.
